Cuentas de usuario

Qué son, dónde viven y cómo se administran

¿Qué es una cuenta de usuario?

Identidad

Nombre de usuario y un número único (UID en Linux, SID en Windows).

+

Credenciales

Lo que demuestra que eres tú: contraseña, PIN, huella, llave.

+

Permisos

Lo que la cuenta puede leer, cambiar o ejecutar.

// Tipos de cuenta

Administrador

root en Linux, Administrador en Windows. Control total del sistema.

Estándar

Uso diario. Puede trabajar, pero no cambiar el sistema.

Invitado

Acceso temporal y muy limitado. En Windows viene deshabilitada.

De servicio

La usa un programa, no una persona; por ejemplo, un servidor web.

¿Dónde guarda el sistema las cuentas?

Linux

/etc/passwd — datos de cada cuenta

/etc/shadow — contraseñas en hash (solo root)

/etc/group — grupos y sus miembros

Windows

SAM — cuentas locales del equipo

Active Directory — cuentas de un dominio empresarial

Cuenta Microsoft — cuenta en línea vinculada al equipo

Administrar cuentas en Linux

// haz clic en un comando para probarlo en el laboratorio

sudo groupadd estudiantes
Crea el grupo estudiantes
sudo useradd -m -s /bin/bash ana
Crea la cuenta ana con su carpeta personal
sudo passwd ana
Asigna o cambia la contraseña
sudo usermod -aG estudiantes ana
Añade a ana al grupo, sin quitarle los otros
id ana
Muestra su UID, su grupo y sus grupos
sudo usermod -L ana
Bloquea su contraseña (-U la desbloquea)
sudo userdel -r ana
Elimina la cuenta y su carpeta personal

Permisos y roles

Quién puede hacer qué con cada archivo

Permisos en Linux: rwx

ls -l notas.txt
-rw-r-----  1  ana  estudiantes  2048  oct 15 08:00  notas.txt
-Tipo: archivo (d = carpeta)
rw-Dueño: ana — lee y escribe
r--Grupo: estudiantes — solo lee
---Otros — nada
r

Leer

Archivo: ver el contenido
Carpeta: listar lo que tiene

w

Escribir

Archivo: modificarlo
Carpeta: crear o borrar archivos

x

Ejecutar

Archivo: correrlo como programa
Carpeta: entrar en ella

La notación octal: permisos en números

r= 4
w= 2
x= 1

Ejemplo: 640

6 = 4 + 2 → rw- → dueño

4 = 4 → r-- → grupo

0 = 0 → --- → otros

Calculadora interactiva

000
---------

filas: dueño · grupo · otros   columnas: r w x

// Valores comunes

OctalSímbolosPara qué
755rwxr-xr-xprogramas y carpetas públicas
700rwx------carpeta privada del dueño
644rw-r--r--archivo que todos pueden leer
640rw-r-----archivo para el dueño y su grupo
600rw-------archivo privado

Cambiar permisos y dueños: chmod y chown

chmod 640 notas.txt
Dueño lee y escribe; grupo lee; otros nada
chmod u+x respaldo.sh
Le da al dueño permiso de ejecutar
chmod o-r informe.txt
Le quita la lectura a los otros
sudo chown ana notas.txt
Cambia el dueño a ana
sudo chown ana:estudiantes notas.txt
Cambia el dueño y el grupo a la vez
chmod -R g-w proyecto/
Quita la escritura al grupo en la carpeta y todo lo que tiene

// u = dueño · g = grupo · o = otros · a = todos  |  + añade · - quita · = fija

Herencia

Lo que se crea dentro de una carpeta recibe sus permisos. Por eso se configuran las carpetas, no cada archivo.

icacls en la consola

icacls notas.txt
ver los permisos
icacls notas.txt /grant ana:R
darle lectura a ana
icacls notas.txt /remove ana
quitarle los permisos

Seguridad de las cuentas

Menor privilegio, contraseñas y MFA

El principio de menor privilegio

Cuenta de administrador

› Instala programas y cambia el sistema

› Si se infecta, el malware controla todo

› Úsala solo cuando haga falta

Cuenta estándar

› Trabajo diario: documentos, navegador, correo

› Pide permiso para los cambios grandes

› Limita el daño de un error o un ataque

// Cuando hace falta más poder

Linux

sudo pide tu contraseña y ejecuta un solo comando como administrador.

Windows

El Control de Cuentas de Usuario (UAC) pide confirmación o la contraseña del administrador.

Contraseñas que sí protegen

✓ Sí

› Frases largas: «mi perro come mangos los martes»

› Una contraseña distinta para cada servicio

› Un gestor de contraseñas para recordarlas

› Cambiarla de inmediato si hay sospecha

✗ No

› Datos personales: nombre, fecha de nacimiento

› Palabras comunes: 123456, password, admin

› Usar la misma en todas partes

› Anotarla en un papel pegado al monitor

Bloqueo de cuenta

Tras varios intentos fallidos, el sistema bloquea la cuenta por un tiempo.

Esto frena a quien intenta adivinar la contraseña probando miles de combinaciones (fuerza bruta).

Autenticación multifactor (MFA)

1

Algo que sabes

Contraseña o PIN

2

Algo que tienes

Teléfono con una app de códigos o una llave de seguridad

3

Algo que eres

Huella dactilar o reconocimiento del rostro

✓ Sí es MFA

Contraseña + código en el teléfono

✗ No es MFA

Contraseña + pregunta de seguridad (las dos son «algo que sabes»)

Señales de alerta que un técnico debe encontrar

! Cuentas compartidas

Varias personas usan la misma cuenta: nadie responde por lo que se hace.

! Exempleados activos

Cuentas de personas que ya no trabajan ahí y siguen habilitadas.

! Todos son administradores

Se violó el menor privilegio: un error o un virus afecta a todo.

! Invitado habilitado

La cuenta de invitado activa abre una puerta sin contraseña.

! Contraseñas débiles o anotadas

Fáciles de adivinar o a la vista de cualquiera.

! Permisos para «Todos»

Carpetas con información sensible que cualquiera puede leer.

Práctica guiada en Linux

sudo groupadd contabilidad
1. Crea el grupo del departamento
sudo useradd -m -G contabilidad luis
2. Crea a luis dentro del grupo
sudo passwd luis
3. Asigna su contraseña
sudo mkdir /srv/contabilidad
4. Crea la carpeta compartida
sudo chown root:contabilidad /srv/contabilidad
5a. El grupo será contabilidad
sudo chmod 770 /srv/contabilidad
5b. Solo el dueño y el grupo entran
ls -ld /srv/contabilidad ; id luis
6. Verifica el resultado
